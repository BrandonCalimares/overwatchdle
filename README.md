# ![Logo](https://i.ibb.co/sp4qH6LW/overwatchdle.webp)

Juego inspirado en Loldle; el objetivo es adivinar el personaje de Overwatch del día según ciertos aspectos en cada uno de los modos.

## Modos de juego

- Clásico: características del personaje como: nombre, rol, edad, etc.
- Frase: Frase dicha por el personaje en el juego.
- Habilidad: Icono de alguna habilidad del personaje.
- Emoji: 5 emojis que representan al personaje.

## Idiomas

El juego está disponible tanto en español latino como en inglés.

## Tecnologías

- HTML
- CSS
- JavaScript
